Importante:
Você não precisa escrever manualmente o package-lock.json nem o conteúdo da pasta node_modules. O npm cria esses itens automaticamente.

1. server.js

É o servidor Node.js. Ele utiliza o Express e disponibiliza a pasta public para o navegador.

server.js 
const express = require('express');

const app = express();
const PORT = 3000;

app.use(express.json());

app.use(
  express.static('public')
);

app.listen(PORT, () => {
  console.log(
    `Walker CRM rodando na porta ${PORT}`
  );
});

2. package.json

Guarda as informações do projeto Node.js e as dependências utilizadas.

package.json 
{
  "name": "walker-crm",
  "version": "1.0.0",
  "description": "Walker CRM",
  "main": "server.js",

  "scripts": {
    "start": "node server.js"
  },

  "dependencies": {
    "express": "^5.1.0"
  }
}

3. banco.json

É o banco de dados inicial do projeto. Depois vamos aprender como salvar clientes, conversas, vendas e outros dados.

banco.json

}

4. package-lock.json

Esse arquivo é criado automaticamente quando você executa npm install.

package-lock.json 
Este arquivo é gerado automaticamente pelo npm.

Não é necessário escrever manualmente.

Comando:

npm install

5. node_modules/

Pasta criada automaticamente pelo npm. Ela guarda as bibliotecas instaladas para o projeto.

node_modules/ 
Esta pasta é criada automaticamente.

Comando:

npm install

Não coloque arquivos manualmente dentro dela.

6. public/index.html

É a página principal que o navegador vai abrir. Aqui ficará a interface do Walker CRM e também o conteúdo do curso.

public/index.html 
<!DOCTYPE html>

<html lang="pt-BR">

<head>

  <meta
    charset="UTF-8"
  />

  <title>
    Walker CRM
  </title>

</head>

<body>

  <h1>
    Walker CRM
  </h1>

  <script

</body>

</html>
